# Contributing to SkillHanger

Thanks for helping. SkillHanger is a small, free, native macOS app, and contributions of any size are welcome.

## Set up

Requirements: macOS 13+, Swift 6 toolchain (Xcode 16 or newer).

```sh
git clone https://github.com/icarus2419/SkillHanger.git
cd SkillHanger
swift test        # run the test suite
make app          # build dist/SkillHanger.app
```

## Ground rules

- **No third-party runtime dependencies.** The app is SwiftUI and AppKit only.
- **Privacy first.** Never log or store prompts, transcripts, credentials, or responses. Usage and task records stay metadata-only.
- **Add a test** for behavior changes. Tests live in `Tests/`.
- **UI changes:** attach before and after screenshots. Render isolated previews with `python3 scripts/render-ui-previews.py` (see the README).
- Keep pull requests focused. One change per PR is easiest to review.

## Adding a package to the Skill Library

Catalog data is generated by `scripts/refresh-marketplace-catalog.py`. Open an issue with the GitHub link and a one-line description, or send a PR that updates the script's sources.

## Reporting bugs

Use the issue templates. Include your macOS version, app version (SkillHanger → About), and whether you use Claude Code, Codex, or both.
